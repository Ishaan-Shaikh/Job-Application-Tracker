About JobTrack

Simple, clean, and to the point

This is a lightweight job tracking application built with vanilla HTML, CSS, and JavaScript. It uses localStorage to save your job applications — no backend required. Navigate between pages and manage your job search easily.

✨ Features

  • Dashboard with status counts
  • Add, edit, delete job applications
  • Status tracking (Applied, Interview, Offer, Rejected)
  • Data persists in your browser
  • Fully responsive UI

Built as a simple multi-page demo — separate HTML files, shared CSS and JS.
